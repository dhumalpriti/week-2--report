This Week 2 report focuses on data collection, cleaning, and preprocessing for logistics analysis. The project simulates a practical logistics data preparation workflow using a synthetic shipment dataset. The dataset contains shipment ID, date, origin, destination, distance, shipment weight, delivery duration, fuel consumption, transportation cost, and on-time delivery status. A few data-quality issues are intentionally included so that preprocessing methods can be demonstrated clearly.

The project begins with data collection simulation. A structured CSV file is used as the reference dataset for shipment records. Before analysis, the data is inspected for incorrect data types, missing values, invalid numerical values, and duplicate shipment records. Python and the pandas library are used to perform these checks and transformations.

Missing delivery-duration values are handled using the median because it provides a robust central value and is less affected by extreme observations than the mean. An invalid non-positive shipment weight is treated as a missing value and replaced using the median weight. Duplicate shipment IDs are checked and removed where necessary. Dates and numerical columns are converted into appropriate formats so that later analysis can be performed reliably.

The project also demonstrates Min-Max normalization for distance, shipment weight, and cost. Normalization converts numerical variables to a common 0-to-1 scale, which can be useful for machine-learning algorithms and comparisons when variables have different units and ranges.

The final cleaned dataset is saved as a separate CSV file. This workflow improves consistency and reduces the risk of incorrect conclusions caused by poor-quality data. In a real logistics organization, the same process could be extended with larger datasets, automated validation rules, outlier analysis, feature engineering, and database pipelines. The dataset used here is synthetic and is intended only for educational and internship demonstration purposes.
