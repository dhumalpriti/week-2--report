# Logistics Week 2 Project
Topic: Data Collection, Cleaning, and Preprocessing for Logistics Analysis.

Files:
- raw_logistics_data.csv
- preprocess_logistics.py
- cleaned_logistics_data.csv
- report_description.txt
- requirements.txt

Run: pip install -r requirements.txt
Then: python preprocess_logistics.py

Techniques: data-type conversion, missing-value handling, invalid-value correction,
duplicate checking, and Min-Max normalization.

Dataset is synthetic and for educational use.
